# Contributing

Thanks for helping improve this incident analysis.

## How to Contribute

1. Fork the repo and create a branch: `git checkout -b improve/playbook-clarity`
2. Make your change. Keep language clear, practical, and defensive.
3. If you change a checklist item, keep the checkbox format: `- [ ]` or `- [x]`
4. Open a pull request with a short description of what you changed and why.

## Guidelines

- **Do NOT** add real IP addresses, real PCAPs, real client names, or exploit code.
- **Do** add defensive guidance, clearer steps, better diagrams, or corrections to NIST CSF mapping.
- **Do** keep the tone professional and educational.
- **Do** test any firewall / IDS/IPS commands in a lab before suggesting them.

## Good First Contributions

- Fix a typo or clarify a step in the playbook
- Add a diagram for network segmentation
- Add a template for post-incident review notes
- Translate the README summary into another language

## Code of Conduct

Be respectful, be constructive, and assume good intent. This is a learning repo.
