# Security Policy

## Reporting a Security Issue

This repository is for education and defensive security improvement. It contains no real client data, real IP addresses, or exploit code.

If you find a security issue in this repository itself, such as accidentally committed sensitive data, please:

1. Do NOT open a public GitHub Issue with the sensitive details.
2. Contact the repository owner privately via GitHub, or open a private security advisory if enabled.
3. Describe the issue, where you found it, and how to reproduce it without including sensitive payloads.

## What This Repo Is NOT

- It is NOT a place to publish real incident IPs, PCAPs, or client data.
- It is NOT instructions to launch a DoS attack. Do not test flood techniques against systems you do not own or do not have explicit permission to test.

## Supported Versions

This is a static documentation repository. There are no software releases to patch. Documentation fixes are accepted via pull requests.
